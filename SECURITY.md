# Security Policy

## Supported Versions

| Version          | Supported          |
| ---------------- | ------------------ |
| Latest release   | :white_check_mark: |
| Earlier releases | :x:                |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through
[GitHub Private Vulnerability Reporting](https://github.com/DownAtTheBottomOfTheMoleHole/terraform-azuredevops-naming/security/advisories/new).
Do not open a public issue for a security vulnerability before the disclosure
has been coordinated.

Include the affected version, a clear description of the impact, steps to
reproduce the issue or a proof of concept, and any relevant logs or tool
output. Please avoid including credentials or other sensitive data in a report.

## Disclosure Process

We aim to acknowledge a vulnerability report within 7 calendar days and will
provide a status update within 30 days while the report is being assessed.
After a fix is available, we will coordinate disclosure with the reporter when
practical.
